# Atlas Bull

Site institucional estático: HTML/CSS/JS, sem build ou backend. Arquivos e assets próprios da marca; Manrope com OFL em assets/manrope-OFL.txt. Design adaptado do Positivus, com créditos e CC BY 4.0 no rodapé.

## Publicar no GitHub Pages

No GitHub Desktop: criar repositório atlas-bull com Local path apontando para a pasta pai publicacao. Os arquivos já estão na subpasta atlas-bull. Conferir alterações, fazer Commit to main e Publish repository. Desmarcar Keep this code private para publicação gratuita pelo plano GitHub Free.

No GitHub: Settings > Pages > Source: Deploy from a branch > Branch: main > Folder: / (root) > Save. Custom domain em branco. Endereço esperado na conta Phoc01: https://phoc01.github.io/atlas-bull/ . Conferir o endereço efetivamente exibido pelo GitHub após a publicação.

.nojekyll faz servir os arquivos estáticos. Os caminhos relativos funcionam no subdiretório atlas-bull. A meta robots permite indexação, sem garantir aparecer nos resultados da busca. Sem domínio próprio, sem APIs ou credenciais. Nunca adicionar pastas internas do Atlas/Office, fotos de clientes ou dados privados neste repositório.

As demonstrações usam dados fictícios e não executam processamento real. Os links de WhatsApp abrem uma conversa para o visitante revisar e enviar. Não há envio automático.
